# GFX Offline Racing

An offline arcade racing game built with **Godot 4.7**, targeting **Android** and
desktop. Races run against AI opponents on the same device, and a second player
can join over a local network (LAN) without any online service.

Everything in this repository is source: scenes, scripts, models, textures,
audio and fonts are all generated by scripts included in `tools/`, so the project
can be rebuilt from scratch.

## Features

- **Three circuits** generated procedurally from control polygons: City Circuit,
  Forest Track and Desert Road, each with its own theme, scenery and surface.
- **Six cars** with distinct acceleration, top speed, handling and braking stats,
  plus a paint colour picker in the garage.
- **Twelve-lap races** with ordered checkpoint gates, lap timing, best-lap
  tracking and a results table.
- **AI opponents** that follow a curvature-aware racing line, brake for corners
  before they arrive, and recover to the track when they run wide.
- **Local LAN multiplayer** using Godot's high-level multiplayer API with
  authoritative host state replication.
- **Full UI flow**: splash, main menu, mode select, track select, car garage,
  settings, LAN lobby, race HUD, pause and results.
- **Touch controls** and gamepad support in addition to keyboard.
- **Performance presets** so the game runs on low-end Android hardware.

## Requirements

- [Godot 4.7](https://godotengine.org/download) (standard build, not .NET)
- Python 3 to regenerate binary assets (optional; the generated files are
  committed)

## Running

```bash
# Open the project in the editor
godot --path .

# Or run it directly; the splash screen is the main scene
godot --path . res://scenes/ui/Splash.tscn
```

The first launch imports all assets and may take a few seconds.

## Controls

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Steer | `A` / `D` or arrow keys | Left stick |
| Accelerate | `W` | Right trigger |
| Brake / reverse | `S` | Left trigger |
| Gear up | `E` | `B` |
| Gear down | `Q` | `A` |
| Drift | `Space` | Right stick click |
| Pause | `Esc` | — |

Player two uses the arrow keys plus `,` and `.` when two players share a device.

## LAN multiplayer

1. Both devices must be on the same network.
2. On the host, choose **LAN → Create room**. The lobby shows the local IP
   address and the port.
3. On the other device, choose **LAN → Join room** and enter that address.
4. The host starts the race once both players are in the lobby.

The host is authoritative: it simulates every car and broadcasts state to the
clients, which interpolate between snapshots.


## Regenerating assets

```bash
python3 tools/make_assets.py
```

This rewrites every file under `assets/`. Re-run the Godot import afterwards.

## Tests

Two layers of checks are included.

**Static validation** parses every script, loads every scene, and verifies that
resource references, input actions, RPC annotations and `class_name`
declarations all resolve:

```bash
godot --headless --path . --script tools/validate.gd
```

**Runtime harness** builds real tracks, simulates a race with an AI driver and
exercises the lap tracker and network payloads:

```bash
godot --headless --path . res://scenes/tools/TestHarness.tscn
```

Both currently report **PASS** with zero failures.

## Android export

1. Install the Android export templates from the Godot editor.
2. Set `renderer/rendering_method.mobile` to `gl_compatibility` (already set).
3. Configure an Android SDK path under **Editor Settings → Export → Android**.
4. Add an Android preset and export an APK or AAB.

Touch controls appear automatically on touch devices.
